Ignition Lab — static website package

Upload all files in this folder to the root of the GitHub Pages repository:
- index.html
- wechat-qr.png
- robots.txt
- sitemap.xml
- favicon.svg

The sitemap and canonical URL are configured for:
https://kirillkim86.github.io/ignitionlab-asia/

If the website URL changes, update the canonical URL in index.html and the URLs in robots.txt and sitemap.xml.

Note: robots.txt and sitemap.xml help crawlers discover the site; they do not guarantee indexing or ranking.
